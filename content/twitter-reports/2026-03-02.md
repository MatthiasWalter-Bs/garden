## Steipete / OpenClaw News

### 🦞 Major Announcement: OpenAI + OpenClaw Foundation

**Peter Steinberger (@steipete)** hat einen bedeutenden Karriereschritt angekündigt:

- **Er tritt OpenAI bei**, um an Agent-Technologie für alle zu arbeiten
- **OpenClaw wird zu einer unabhängigen Foundation** überführt und bleibt Open Source
- OpenAI sponsert das Projekt bereits und ermöglicht Peter, Zeit für die Community zu investieren

> *"My next mission is to build an agent that even my mum can use"* — Peter Steinberger

**Vision:** Ein Agent, der sicher, produktiv und für jeden nutzbar ist — mit Zugang zu den neuesten Modellen und Forschungsergebnissen.

### 🚀 Latest Release Highlights (v2026.03.02)

**Neue Features:**
- **Adaptive Thinking:** Claude 4.6 Modelle nutzen jetzt standardmäßig adaptive Thinking-Level
- **Health Endpoints:** Neue `/health`, `/healthz`, `/ready`, `/readyz` Endpunkten für Docker/Kubernetes
- **Android Nodes Erweiterung:** `camera.list`, `device.permissions`, `device.health`, `notifications.actions`
- **Discord Thread Bindings:** Inaktivitäts-basierte Lebenszyklen (`idleHours` statt fixed TTL)
- **Telegram DM Topics:** Topic-spezifische Konfiguration für Direct Messages
- **Web UI i18n:** Cron-Seite jetzt in Englisch und Chinesisch (zh-CN) verfügbar
- **OpenAI WebSocket:** WebSocket-first Streaming für OpenAI Responses API
